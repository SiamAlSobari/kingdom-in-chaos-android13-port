# Kingdom in Chaos (v1.0.5) - Android 13/14+ Port

Compatibility port and source repository for Kingdom in Chaos v1.0.5 (`com.droidhang.zhanshen` / 战神传说, released by Droidhang).

## Overview

Kingdom in Chaos shares the Cocos2d-x 2.x engine architecture, asset structures, and gameplay systems with Pocket Heroes.

- Package Name: `com.droidhang.zhanshen`
- Main Activity: `com.droidhang.ph.GameActivity`
- Version: 1.0.5 (versionCode 6)
- Original Target SDK: 20 (Android 4.4 KitKat)
